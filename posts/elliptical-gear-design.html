基于 CATIA 的椭圆齿轮副参数化设计

📅 2026年8月3日  |  🏷️ 椭圆齿轮 · CATIA · 参数化设计 · 非圆齿轮

摘要

针对椭圆齿轮副的应用需求，以及在缺乏二次开发能力的情况下，提出了一种生成椭圆齿轮三维数学模型的方法。该方法可在仅使用基础模块的 CAD 软件 CATIA 中实现。首先，给出了椭圆齿轮副的基本公式以及常见设计流程中的设计参数。其次，提供了一个数值实例，以实际方式展示设计输入与输出。最后，提出了一种逐步生成 CATIA 三维数学模型的方法。该方法可帮助工程师在工程实践中方便地应用椭圆齿轮副。

关键词：椭圆齿轮，节曲线，CAD，参数化设计，CATIA

引言

在汽车空调模块中，通常采用运动学连杆和连杆系统（即“机构”）来驱动风门 [1]。特别常见的是，空调模块中采用两个温度风门来调节温度，一个控制热风，另一个控制冷风。在传统机构设计中，采用多连杆或齿轮副来连接两个风门，并由一个执行器驱动。与传统设计不同，椭圆齿轮副具有可变传动比，在此应用中可以改善空调的温度线性度性能。

非圆齿轮理论经过多年发展 [2]。Litvin [3] 推导了非圆齿轮的广义节曲线，以及作为特例的椭圆齿轮节曲线。Chang 等 [4] 提出了数学模型和根切分析，有助于高精度椭圆齿轮的设计。此外，Bair [5] 提出了一种非标准椭圆齿轮传动的 CAD 方法，并编写计算机程序计算设计参数。随着 SolidWorks 和 CATIA 等软件在 CAD 中的广泛应用，椭圆齿轮的设计方法受到一些研究的关注。Hu 等 [6] 提出了一种基于 Visual Basic 6.0 作为 SolidWorks 二次开发工具的椭圆齿轮参数化设计方法。Yan 等 [7] 开发了一个利用 SolidWorks 二次开发生成共轭椭圆节曲线的设计系统。

然而，并非所有公司都具备 CATIA 和 SolidWorks 的二次开发能力，这制约了椭圆齿轮的广泛应用。本文专注于仅使用 CATIA 基础模块、无需计算机编程的椭圆齿轮参数化设计方法。文中给出了生成三维数学模型的数值示例。这将有助于工程师在无需二次开发的情况下，利用 CATIA 方便地设计椭圆齿轮。

椭圆齿轮的设计参数

椭圆齿轮的节曲线可用极坐标表示为：

r = a ( 1 − e2 ) 1 + e cos ( n φ )
(1)

其中，r 为节曲线半径，φ 为逆时针测量的角度，a 为椭圆长半轴，e 为偏心率，n = 1, 2, … 为椭圆阶数。图1 a) 展示了 n = 0 时，节曲线退化为标准圆。图1 b), c), d) 分别展示了 n = 1, 2, 3 时，椭圆节曲线的形状。

📊 图1：不同阶数 n 下的椭圆形态（待绘制）

利用方程 (1)，可以在 CATIA 草图中使用 “样条线” 工具，通过设置一系列不同 φ 和 r 的控制点来获得节曲线。然而，在常见设计方法中，设计参数为模数 m 和齿数 z，而非长半轴 a。其中 m 为齿轮模数，z 为齿数。

模数和齿数应满足如下方程：

C = π m z
(2)

其中 C 为节曲线的弧长，可按下述方法求得。

首先，将节曲线方程写成笛卡尔坐标系形式：

{ x(φ) y(φ) } = { a ( 1 − e2 ) cos φ 1 − e cos ( n φ ) a ( 1 − e2 ) sin φ 1 − e cos ( n φ ) }
(3)

其次，通过积分计算弧长：

C = ∫ 0 2π ( x˙ ( φ ) ) 2 + ( y˙ ( φ ) ) 2 d φ
(4)

最后，简化积分后，弧长 C 可表示为：

C = a ( 1 − e2 ) ∫ 0 2π [ ( 1 − e cos n φ ) 2 + n2 e2 sin2 n φ ] 1/2 ( 1 − e cos n φ ) 2 d φ
(5)

该积分无法解析求解，但可通过计算机编程或甚至 Excel 公式进行足够精度的数值近似。图2展示了利用黎曼和近似弧长的 Excel 方法，其中 Δφ = 0.001。输入参数为模数 m、齿数 z、偏心率 e 和阶数 n。弧长 C 可通过方程 (5) 的黎曼和近似得到，长半轴 a 可由方程 (2) 计算得出。

📊 图2：黎曼和近似弧长确定设计参数（待绘制）

考虑一个椭圆齿轮，其长半轴为 a1，偏心率为 e1，阶数为 n1。设计椭圆齿轮副需要共轭节曲线。给定共轭节曲线的阶数 n2 作为输入参数，其余参数可按如下方式确定。以下方程简化自 Yan [8] 的研究。

a2 = a1 n2 − e12 ( n2 − 1 )
(6)
e2 = e1 n2 − e12 ( n2 − 1 )
(7)

其中 n 定义为：

n = n2 n1
(8)

此外，两回转中心距可按下式获得：

A = a1 [ 1 + n2 − e12 ( n2 − 1 ) ]
(9)

根据设计参数，共轭齿轮的节曲线可由方程 (1) 得到，齿数可由方程 (2)、(5) 计算。

图3 a) ~ d) 给出了 n 为不同数值时符合啮合条件的共轭节曲线。

CATIA 三维建模方法

确定设计参数后，可在 CATIA 草图中创建多个控制点。如图4所示，线段长度通过方程 (1) 约束其角度。参数为表1中的齿轮2。等式的约束可通过 CATIA 中的 “公式” 命令实现。在本例中，控制点每隔 5° 计算一次。由于椭圆齿轮的对称性，只需第一和第二象限的控制点。通过 “样条线” 命令连接控制点，可生成近似的节曲线。增加控制点数量有助于提高曲线精度。

📊 图4：每5°约束的控制点（待绘制）

每个齿的位置可通过草图中的 “等距点” 命令找到，齿数作为输入变量。图5展示了椭圆节曲线被等弧长分为63个点的示例。

📊 图5：节曲线按等弧长均分为63个点（待绘制）

椭圆齿轮的齿廓为渐开线，通常通过模拟齿条刀具的纯滚动方法获得 [9]。该方法在无二次开发的 CATIA 中过于复杂。因此，本文采用替代方法。其理论由 Litvin [10] 论证。如图6所示，椭圆齿轮的齿廓可用圆齿轮的齿替代，该圆齿轮的分度圆半径等于椭圆上该点的曲率半径。圆齿轮的齿廓为圆的渐开线，可方便地在 CATIA 草图中绘制。

📊 图6：椭圆齿轮上的齿廓由在位置点处与椭圆相切的圆齿轮齿替代（待绘制）

将所有轮齿替换为相应的圆齿轮齿后，即可最终生成椭圆齿轮的齿廓。图7显示了在 CATIA 中生成完整的三维数学模型。

📊 图7：椭圆齿轮三维数学模型（待绘制）

结论

本文重点介绍了椭圆齿轮副的设计方法。给出了椭圆齿轮副的设计参数，以及无需二次开发即可确定这些参数的常见设计流程。最后，通过数值示例，详细介绍了生成椭圆齿轮三维数学模型的逐步方法。该三维建模方法可帮助工程师方便地进行椭圆齿轮的 CAD 工作，并为椭圆齿轮的广泛应用提供便利。
